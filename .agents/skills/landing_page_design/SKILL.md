# Landing Page Design Guidelines

When asked to design or improve a landing page, follow these "Impeccable" principles:

## 1. Visual Hierarchy and Layout
- **Hero Section First:** The hero section is the most important part of the page. It must contain a strong headline, a clear subheadline, and a primary Call To Action (CTA).
- **Whitespace / Negative Space:** Give elements room to breathe. Use generous padding and margins to group related elements and separate distinct sections.
- **Grid Systems:** Use CSS Grid or Flexbox to maintain consistent alignment.

## 2. Typography
- **Modern Sans-Serif:** Use system fonts or modern sans-serifs (Inter, Roboto, SF Pro) for clean legibility. Avoid default browser serif fonts unless specifically requested.
- **Contrast & Scale:** Use distinct font sizes for `h1`, `h2`, `h3`, and `p`. Ensure high contrast between text and background.

## 3. Micro-Interactions & Animation
- **Hover States:** All interactive elements (buttons, links, cards) must have clear hover states.
- **Subtle Entrance Animations:** Use gentle fade-ins and slide-ups for elements as they enter the viewport. Do not over-animate; prioritize performance and subtlety.

## 4. Components & Iconography
- **Icons:** Always use vector icons (e.g., `lucide-react`) instead of text symbols or emojis for professional UI.
- **Glassmorphism / Elevation:** Use subtle shadows (`box-shadow`) and backdrop blurs (`backdrop-filter: blur()`) to create depth and layering in modern themes.
- **Calls to Action (CTAs):** Primary buttons should be highly visible (vibrant accent color) and secondary buttons should have less visual weight (ghost buttons or outlines).

## 5. Avoid "AI Slop"
- Do not use generic, unstyled components.
- Do not use clashing color palettes. Stick to a primary accent color, dark/light surface colors, and semantic status colors.
- Ensure all designs are responsive and adapt gracefully to mobile viewports.
